# Monochrome (native iOS)

A small native SwiftUI music player rebuilt from the Monochrome web app. Plays
audio files you import from the Files app. Built as a SwiftPM package for xtool,
cross-compiled from Linux.

> Work in progress. The README is completed in the final milestone; the
> authoritative state lives in `docs/PROGRESS.md`.

```bash
swift test
scripts/build.sh
```
